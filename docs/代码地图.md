## 模块 / 目录划分

| 模块/目录 | 职责 | 关键文件 |
|---|---|---|
| `install.sh` | 即装即用入口：App + 插件 + hook + **OS 默认 App** + doctor | 根目录 |
| `plugins/md-reader/` | Grok 插件：命令/skill/hook/映射表 | `config/readers.example.json` |
| `plugins/md-reader/scripts/apply_os_defaults.py` | 按映射写/查 Launch Services；doctor | + `ls_default_handler.swift` |
| `plugins/md-reader/scripts/install_sidechannel_hook.sh` | 可靠安装侧信道 hook → `~/.grok/hooks/` | |
| `plugins/md-reader/skills/open-md/scripts/open_path.py` | `/open` 兜底打开（与 OS 策略同源） | |
| `plugins/md-reader/hooks/on_md_write.py` | PostToolUse 写 last_path + history | `hooks.json`（包内，不可靠） |
| `plugins/md-reader/commands/` | slash：`open.md` · `preview.md` | |
| `viewer/` | MdReader.app（Swift+WKWebView） | `Sources/.../main.swift`、`scripts/build_app.sh` |
| `tests/` | open_path + apply_os_defaults + on_md_write | `pytest` |
| `docs/` | 架构/路线/ADR/手册/地图/playbooks | 见分层 |

## 加新东西放哪

- 新扩展名路由 → `config/readers.example.json` 的 `by_extension` + `apps`（补 `bundle_id`）+ 必要时 `os_defaults.apply_extensions` 与 `EXT_TO_UTI`（`apply_os_defaults.py`）
- 新 slash 命令 → `plugins/md-reader/commands/*.md`
- 渲染窗行为 → `viewer/Sources/MdReaderViewer/main.swift`，改完 `viewer/scripts/build_app.sh --install`
- 侧信道追踪类型 → `on_md_write.py` 的 `TRACKED_EXTS`
- 测试 → `tests/test_*.py`
- 可复跑运维步骤 → `docs/playbooks/` + 本文件操作入口一行
- 接口/坑说明 → `docs/工程手册.md`

## 构建 / 测试 / 运行入口

| 动作 | 命令 |
|---|---|
| 一键安装 | `./install.sh` |
| 只写默认 App | `./install.sh --set-defaults` |
| 自检 | `./install.sh --doctor` |
| 测试 | `python3 -m pytest tests/ -q` |
| 只编 App | `./viewer/scripts/build_app.sh --install` |
| 命令打开 | `python3 plugins/md-reader/skills/open-md/scripts/open_path.py -- <path>` |
| dry-run 打开策略 | `…/open_path.py --dry-run -- <path>` |
