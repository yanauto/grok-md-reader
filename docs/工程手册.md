## 1. 环境与拓扑

| 环境 | 机器/路径 | 入口 | 备注 |
|---|---|---|---|
| 开发机（本机） | 仓库根：`…/projects/grok-md-reader` | `./install.sh` | 需 macOS + Python3 + Xcode CLT（`swiftc`） |
| MdReader 安装位 | `~/Applications/MdReader.app`（优先）或 `/Applications/MdReader.app` | `viewer/scripts/build_app.sh --install` | bundle id `com.yanauto.mdreader` |
| 开发构建产物 | `viewer/dist/MdReader.app` | `build_app.sh`（无 `--install`） | `open_path` 会优先尝试 |
| Grok 插件 | `~/.grok/plugins/md-reader` → 仓库 `plugins/md-reader` | install 内 `ln -sfn` | 改仓库即生效 |
| 插件数据 | `~/.grok/plugin-data/user/md-reader/` | 运行时自动建 | 也可用 `GROK_PLUGIN_DATA` 覆盖 |
| 侧信道 hook | `~/.grok/hooks/md-reader-sidechannel.json` | `scripts/install_sidechannel_hook.sh` | **可靠**路径；包内 hooks.json 可能不注册 |
| Linux | 无 MdReader.app | 插件 + `readers.json` + `xdg-open` | install 对 App 步会失败并提示 |

**依赖**：Grok CLI、Python 3、`swiftc`（编 App）。**无** vault 服务端密钥；本项目不连外网渲染。

## 2. 关键接口 / 命令

### 2.1 安装与自检

| 命令 | 作用 |
|---|---|
| `./install.sh` | 编 App → 链插件 → 装侧信道 hook → 写 OS 默认 → doctor |
| `./install.sh --doctor` | 仅健康检查（`apply_os_defaults.py --doctor`） |
| `./install.sh --set-defaults` | 仅按配置写 Launch Services 默认 |
| `./install.sh --no-set-defaults` | 全装但**不**改默认 App |
| `python3 -m pytest tests/ -q` | 单测 |
| `./viewer/scripts/build_app.sh --install` | 只编/装 App + 注册 scheme |

逐步剧本：`docs/playbooks/install-and-click.md`。

### 2.2 打开路径（运行时）

| 场景 | 机制 |
|---|---|
| 工具行 `file://` **Cmd+点击** | Grok opener → 系统 `open` → **install 写入的默认 App** |
| 聊天纯文本路径 | `/open <path>` 或 agent 调 skill |
| 上次路径 | `/preview` → 读 `last_path` |
| 程序打开 md | `md-reader://open?path=<urlencoded 绝对路径>` 或 `open -a MdReader <file>` |

**`open_path.py`**（`plugins/md-reader/skills/open-md/scripts/open_path.py`）：

- 配置加载顺序：`$GROK_PLUGIN_DATA/readers.json` → 插件内 `config/readers.example.json`
- 按扩展名 `by_extension` → app key；未知 → `default`（通常 `system`）
- `md-reader` / `viewer` → scheme / `open -a MdReader`
- 其它 app key → `apps.<key>.darwin|linux` 命令行；失败可回落 `open`/`xdg-open`
- 退出码：`0` 成功 · `1` 打不开/无 last_path · `2` 参数/拒绝 URL 等
- dry-run：`--dry-run`（测用，不真 open）

### 2.3 映射配置契约（`readers.example.json`）

| 字段 | 含义 |
|---|---|
| `by_extension` | `".md"` → app key（如 `md-reader` / `preview` / `word`） |
| `apps.<key>.bundle_id` | macOS LS 默认用（install 写默认） |
| `apps.<key>.darwin` / `.linux` | `/open` 兜底命令 argv（路径追加在末尾） |
| `os_defaults.apply_extensions` | **install 会改默认的扩展名列表**（不含 `.txt`/`.html`） |
| `default` | 未知扩展名回落（`system`） |

默认映射摘要：`.md/.markdown/.mdc/.mdx` → md-reader；`.pdf` → Preview；Office → Word/PPT/Excel（若装）；`.txt` 等仅 `/open` 可进 MdReader，**不**写 OS 默认。

用户覆盖：

```bash
cp plugins/md-reader/config/readers.example.json \
  ~/.grok/plugin-data/user/md-reader/readers.json
# 编辑后
./install.sh --set-defaults
```

### 2.4 侧信道 hook

- 脚本：`plugins/md-reader/hooks/on_md_write.py`
- 事件：`PostToolUse`，matcher `write|search_replace`（Grok 真名；亦兼容别名）
- 路径字段：`toolInput.file_path`
- 追踪扩展：`TRACKED_EXTS`（md/txt/pdf/office/html…，非代码）
- 关闭：`touch ~/.grok/plugin-data/user/md-reader/hook_disabled` 或 `MD_READER_HOOK_DISABLE=1`

### 2.5 URL scheme / 环境变量

| 名 | 用途 |
|---|---|
| `md-reader://open?path=…` | 唤起 MdReader |
| `GROK_PLUGIN_ROOT` | 插件根（hook/skill 运行时） |
| `GROK_PLUGIN_DATA` | 可写数据目录（覆盖默认 plugin-data） |
| `MD_READER_APP` | 强制 MdReader.app 路径 |
| `MD_READER_HOOK_DISABLE` | 关侧信道 |

## 3. 数据与口径

| 路径 | 内容 | 口径 |
|---|---|---|
| `…/md-reader/last_path` | 最近打开/写入路径一行文本 | `/preview` 读取 |
| `…/md-reader/history/current.json` | 会话可读文件历史 | History 菜单；上限见 hook `MAX_HISTORY=50` |
| `…/md-reader/readers.json` | 用户映射覆盖 | 可选；缺则 example |
| `…/md-reader/hook_disabled` | 存在即关 hook（空/`1`/`true`…） | 删文件恢复 |
| Launch Services | 扩展名 → bundle 默认 App | 由 `apply_os_defaults.py` + `ls_default_handler.swift` 写入 |
| 时区 | 文档与 ADR 日期 | **UTC+8** 表述；文件时间戳以本机为准 |

**安全口径**：只本地文件；viewer 拒绝 URL；过大文件拒绝加载（见 `main.swift`）；无内容上传。

**工作区外路径**：默认拒绝为 ROADMAP **后置**项；实现以当前 `open_path`/viewer 为准，勿在文档假装已强制。

## 4. 稳定坑（再犯必烧时间）

1. **插件包内 `hooks/hooks.json` 不保证注册** — headless 可能看不到 `plugin:…` 的 hook_execution；装侧信道必须跑 `install_sidechannel_hook.sh`（install 已做）。
2. **P1：hook 输出 OSC-8 在 Grok TUI 不可点** — 禁止再设计「hook 打可点链接当主体验」；主路径是 OS 默认 + Cmd+点击。
3. **聊天气泡裸路径不是超链接** — 用户报「点不了」先区分工具行 vs 聊天正文；正文用 `/open`。
4. **改默认 App 是有意侵入** — 卸载观感/用户抱怨时说明 `--no-set-defaults`；`.txt` 故意不写默认以免劫持系统文本。
5. **映射两处同步**：改扩展名既要 `by_extension`/`apps`，写 OS 默认还要 `os_defaults.apply_extensions` **和** `apply_os_defaults.py` 内 `EXT_TO_UTI`（缺 UTI 则 doctor/apply 跳过该类）。
6. **Office 未装** — Word 等 `open -a` 失败会回落 system open；doctor 应反映缺失，体验因环境而异（ADR-0001 已知）。
7. **MdReader 未装 / scheme 未索引** — `/open` 优先 `open -a <app path>`；提示 `./viewer/scripts/build_app.sh --install`。
8. **Grok 工具真名** — payload 为 `write` / `search_replace`（非 Claude 的 `Write`/`Edit`）；matcher 两边兼容但调试 dump 看真名。
